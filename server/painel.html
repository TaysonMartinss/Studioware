Chaves de API

B-rolls e fotos de stock, com uso comercial. A chave é grátis em pixabay.com/api/docs.
Modelos 3D. O token está em sketchfab.com → Settings → Password & API.
Opcional: evita que os roteiros parem quando o login do Claude expira. Num terminal, rode claude setup-token e cole aqui o token.
Como conseguir estas credenciais

Em console.cloud.google.com: crie um projeto, ative a "YouTube Data API v3", configure a tela de consentimento (tipo Externo, com o seu e-mail como usuário de teste) e em Credenciais → Criar credenciais → ID do cliente OAuth → tipo "App para computador" (a "Chave de API" não publica). Por fim, na tela de consentimento, clique em "Publicar app": em modo de teste a Google desconecta o canal após 7 dias. O aviso "app não verificado" ao conectar é normal, porque o app é seu.

Ficam só no arquivo .env deste computador.
