Chaves de API
B-rolls e fotos de stock, com uso comercial. A chave é grátis: crie conta em pixabay.com e copie-a em pixabay.com/api/docs.
Modelos 3D. O token está em sketchfab.com → Settings → Password & API.
Opcional, para os roteiros não pararem quando o login do Claude expira (importante no modo automático). Num terminal corra claude setup-token, entre com a sua conta e cole aqui o token que aparece. Fica só no ficheiro .env deste computador.
Para publicar no YouTube. Em console.cloud.google.com: crie um projeto, ative a "YouTube Data API v3", configure o ecrã de consentimento (tipo Externo, junte o seu e-mail como utilizador de teste) e em Credenciais → Criar credenciais → ID do cliente OAuth → tipo "App para computador" (não use "Chave de API": essa não publica). Cole aqui o ID do cliente e a chave secreta do cliente. Por fim, no ecrã de consentimento, carregue em "Publicar app": em modo de teste a Google desliga o canal ao fim de 7 dias (o aviso "app não verificada" ao ligar é normal, porque a app é sua).
As chaves ficam só neste computador, no ficheiro .env do projeto.
